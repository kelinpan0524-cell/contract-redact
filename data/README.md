# data/：随包分发的只读数据

这里放**跟着安装包一起装到本机**的只读数据：内置词表、示例配置这类东西。
打包时会整体装到 `<Python 环境>/share/contract-redact/data/`，升级包时会被覆盖，
所以不要在这里改自己的东西。

以后要内置默认 keep 列表、行业词表，就放这个目录，随 `pip install` 一起分发。

## 不要放什么

- 真实合同、客户名单、映射表（`*.map.json`）、候选词文件（`*.candidates.json`）
- 任何含原文的脱敏中间产物

映射表、审计日志这些运行时产物默认写在 `~/.contract-redact/`，跟安装目录无关。
